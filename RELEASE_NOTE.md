# NEPSE API v1.0.0

First stable release of a Go-based REST API and MCP server for accessing Nepal Stock Exchange market data.

### Features

- REST API with OpenAPI and Swagger documentation.
- 24 MCP tools for Claude and other MCP-compatible clients.
- Market summaries, indices, securities, historical prices, graphs and floorsheet data.
- Shared NEPSE client with authentication, caching, retries and response validation.
- Symbol-specific floorsheet filtering using paginated market data.

### Supported Platforms

- Linux: AMD64 and ARM64
- Windows: AMD64 and ARM64
- macOS: Intel AMD64 and Apple Silicon ARM64

**Initial stable release.**
